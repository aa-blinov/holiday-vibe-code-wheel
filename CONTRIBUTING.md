# Contributing

Contributions are welcome, especially new project prompts and twists.

## Adding Ideas

Open `src/data/challenges.js`:

- Add base project ideas to `BASE_IDEAS` under `saas`, `devtools`, `apps`, or `holiday`. Keep `short` under 14 characters so it fits cleanly on a wheel slice.
- Add product or aesthetic formats to `TWISTS`.
- Keep copy direct and free of placeholder buzzwords.

## Local Check

```bash
npm install
npm run build
```

Verify there are no build errors before opening a pull request.
