# Daily Vibe-Code Roadmap (15–20 min/day)

Pick **one** small task per day—no overthinking required.

- [ ] **Day 1 — Sound Effects**: Add subtle Web Audio API tick sounds as slices pass the pointer + a celebratory chime on landing.
- [ ] **Day 2 — Confetti Burst**: Trigger a festive gold/emerald/cranberry confetti burst when the wheel stops.
- [ ] **Day 3 — Custom Slices Editor**: Add a drawer to add, remove, or toggle challenges on the wheel.
- [ ] **Day 4 — No-Repeat Toggle**: Add an option to exclude already-built challenges from the wheel.
- [ ] **Day 5 — Build Links in History**: Let users paste a URL or repo link when marking a mission as "Built".
- [ ] **Day 6 — Countdown to New Year**: Add a compact live countdown timer in the header.
- [ ] **Day 7 — Keyboard Shortcuts**: Press `Space` to spin, `Esc` to close the modal.
- [ ] **Day 8 — Export / Import Progress**: Download or restore `localStorage` Advent progress as JSON.
- [ ] **Day 9 — Share Card**: Generate a clean summary text or SVG badge of your Advent streak to share.
- [ ] **Day 10 — Theme Switcher**: Add a second winter theme (e.g., "Frosty Ice" vs "Midnight Pine").
- [ ] **Day 11 — More Challenges**: Expand `src/data/challenges.js` to 25 unique holiday missions.
- [ ] **Day 12 — Mobile Polish**: Add swipe-to-spin gesture support on touch screens.
